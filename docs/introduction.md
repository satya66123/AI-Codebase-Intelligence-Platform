# AI Codebase Intelligence Platform
## Project Introduction

**GitHub:** https://github.com/satya66123/AI-Codebase-Intelligence-Platform.git

### Interview Introduction

I developed a project called **AI Codebase Intelligence Platform** using Python and Streamlit.

The main goal of this project was to build a unified AI-powered application that supports multiple AI providers and models. The platform is designed around eight AI providers and 30 configured models, combining local model support through Ollama with cloud-based AI integrations.

The application also includes repository discovery and code quality analysis capabilities. I organized the application around an application container that coordinates services for provider and model management, repository discovery, source loading, and code quality analysis.

I used PyTest for automated testing and Streamlit to build the user interface.

Through this project, I gained practical experience in Python development, AI-provider integration, multi-model application design, repository-related functionality, and automated testing.
