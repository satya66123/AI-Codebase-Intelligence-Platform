## 7. Versioning Policy

The project follows a proposed semantic versioning approach:

`MAJOR.MINOR.PATCH`

- **MAJOR:** Significant architectural changes or major functionality changes.
- **MINOR:** New features and backward-compatible improvements.
- **PATCH:** Bug fixes and smaller corrections.

Version numbers should be updated when a release is actually prepared and published.
